# أفضل طريقة تستعملني بيها على Antigravity

## 1) الإعداد مرة واحدة
- شغّل `install.bat` → اختار **[2] GLOBALLY** عشان يشتغل في كل مشاريعك.
- في Antigravity: زرار **"…"** فوق بانل الأيجنت → **Customizations** → **Rules** → هتلاقي `AGENTS.md` متقري.
- في الـ model picker اختار **Claude** لشغل الكود والأدوات. سيبه على Gemini للحاجات السريعة الرخيصة.
- الوكلاء: اكتب `/agents` في البانل — المفروض تلاقي الـ12 كلهم.

## 2) وضع التشغيل (مهم جدًا لأدواتك)
- استخدم **Agent-assisted** مش **Agent-driven/Turbo** — إنت بتعدل ريجستري وبتشغل adb، أوتوماتيك كامل هنا خطر.
- في **Terminal Auto Execution**: خلّيه **Auto** مش Turbo، وحط **Deny List**:
  `format`, `reg delete`, `rd /s`, `del /f /s /q`, `diskpart`, `bcdedit`, `fastboot erase`, `fastboot flash`, `adb shell rm`, `pm uninstall` (من غير `--user 0`).
- **Allow List** للآمن: `dotnet build`, `git status`, `adb devices`, `npm run`.

## 3) روتين الشغل اليومي
1. افتح المشروع → اكتب `/go` → بيقرا الميمو ويكمّل. (مش هيقرا المحادثة من الأول)
2. مهمة واحدة في الرن الواحد. "اعمل الأداة كلها" بيولّد شغل مش مراجَع؛ "اعمل شاشة الـsettings" بيولّد شغل صح.
3. بعد كل مهمة خلصت: `/memo`.
4. قبل ما ترفع: `/ship`.
5. لو فيه باج: `/fix <الخطأ>` — لازم تلزق نص الإيرور كامل مش وصف.

## 4) حاجات بتوفر توكنز فعليًا
- بلّغه بالملف اللي يشتغل عليه: `@src/Registry.cs` أحسن من "دور في الكود".
- متسيبش الشات يطول. أول ما يوصل ~40 رسالة: `/memo` → افتح شات جديد → `/go`.
- الخطط الطويلة سيبها لـ `manager`، وبعد كده نفّذ كل خطوة في رن لوحدها.
- متطلبش منه يعيد يكتب الملف كله — قوله "غيّر الدالة الفلانية بس".

## 5) الأوامر الجاهزة
| الأمر | بيعمل إيه |
|---|---|
| `/go` | يقرا الميمو ويكمّل من آخر نقطة |
| `/memo` | يحدّث الملخص |
| `/fix <error>` | يصلّح بطريقة منضبطة (3 محاولات بحد أقصى) |
| `/ship` | تشيك النشر + QA + مراجعة مستخدم |
| `/newtool <فكرة>` | يبدأ أداة جديدة بهيكل جاهز |
| `/site <اسم الأداة>` | صفحة هبوط + بوستات ترويج |
| `/review` | مراجعة المدير للشغل الحالي |

## 6) IDEs مخصصة لكلود (لو حبيت تجرب)
- **Claude Code** — الأقرب لشغلك. موجود في التيرمنال، وكمان إضافة لـ **VS Code** و**JetBrains**، وتبويب Code جوه **Claude Desktop**. الوكلاء والسكيلز والأوامر دي كلها اتصممت أصلًا عليه، فبيشتغلوا بأعلى كفاءة هناك.
- **Claude Cowork** — للشغل اللي مش كود: بحث، تحليل، كتابة، ملفات كتير.
- **Claude in Chrome** — يشوف المتصفح ويجرب موقعك بنفسه.
- الخلاصة: خلي **Antigravity** للتجربة السريعة، و**Claude Code** للشغل الجاد على الأدوات — نفس الملفات بتشتغل في الاتنين.
