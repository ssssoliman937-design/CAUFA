# CAUFA LEAGUE - eFOOTBALL 26 Tournament Tracker & Memory Vault

موقع رياضي إلكتروني متكامل لمتابعة بطولات **eFOOTBALL 26** الخاصة بـ **CAUFA LEAGUE**، يحتوي على المجموعات، الأدوار الإقصائية، الترتيب المباشر، ترتيب الهدافين، وأرشيف ذاكرة البطولات السابقة.

---

## 🚀 طريقة الرفع والاستضافة على GitHub Pages (في 3 خطوات):

1. **إنشاء مستودع جديد على GitHub**:
   - توجه إلى موقع [GitHub.com](https://github.com) وأنشئ المستودع باسم `caufa-league` أو `pes`.

2. **رفع ملفات المشروع**:
   - ارفع جميع ملفات هذا المجلد (`index.html`, `style.css`, `app.js`, المجلد `assets`).

3. **تفعيل GitHub Pages**:
   - اذهب إلى **Settings** > **Pages** داخل مستودعك على GitHub.
   - اختر الفرع `main` ثم احفظ `Save`.
   - سيعطيك GitHub رابط موقعك المباشر مثل: `https://your-username.github.io/caufa-league/`

---

## 🔐 لوحة تحكم المنظم (CAUFA Admin):
- **كلمة المرور**: `Ss`
- **التشـفير**: `SHA-256`

---

## 🌐 المزامنة المباشرة أونلاين:
الموقع مجهز بمحرك مزامنة أونلاين لحظي (Realtime Cloud Engine)، حيث يظهر أي تعديل في النتائج أو المجموعات من الأدمن فورياً عند جميع المتابعين والزوار في نفس اللحظة!
